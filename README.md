# Harsha Hegde Kondadakuli: Emcee Portfolio

Static site. No build step.

## Publish on GitHub Pages
1. Create a repository, upload everything in this folder (keep `.nojekyll`).
2. Settings > Pages > Deploy from a branch > `main` > `/ (root)`.
3. Live at `https://<username>.github.io/<repo>/`.

## Edit
Only `config.js` needs editing: phone, email, photos, videos.
- Photos: file path in `assets/gallery/`, a Google Drive share link, or any image link.
- Videos: YouTube, Google Drive, Vimeo, an mp4 in `assets/videos/`, or any link.
- Google Drive files must be shared as "Anyone with the link".
- Keep repo videos under 100 MB. For longer ones use YouTube or Drive.
